# ToCal — คู่มือฉบับสมบูรณ์ (สำหรับผู้เริ่มจากศูนย์)

> เอกสารนี้อธิบายทุกอย่างของ **TokenCal** ตั้งแต่ "มันคืออะไร" จนถึง "ใช้จริงทุกวันยังไง" และ "พังแล้วแก้ยังไง"
> ไม่ต้องมีพื้นฐานเขียนโปรแกรมเลย — ทำตามทีละขั้นได้เลย

> **⚡ อยากเริ่มเลย (สรุปสั้น):**
> 1. ติดตั้ง **Violentmonkey** ในเบราว์เซอร์ แล้วเพิ่มสคริปต์จากไฟล์ `Claude.js` (หัวข้อ 3)
> 2. ติดตั้ง **Node.js** แล้วเปิด autostart: ดับเบิลคลิก `setup-autostart-windows.vbs` (Windows) หรือ `setup-autostart-macos.command` (macOS)
> 3. เปิด claude.ai → แผง TokenCal → **ตั้งค่าโฟลเดอร์** → **จับคู่อัตโนมัติ** → ใส่โฟลเดอร์ปลายทาง → บันทึก
> 4. จบ! ตั้งแต่นี้นับและเซฟไฟล์อัตโนมัติทุกครั้งที่ Claude ตอบจบ
> 5. ติดตรงไหน → หัวข้อ 11 (แก้ปัญหา) หรือ 12 (คำถามที่พบบ่อย)

## 1. TokenCal คืออะไร

เวลาเราคุยกับ Claude แต่ละข้อความที่พิมพ์และคำตอบที่ได้ จะถูกคิดเป็นหน่วยย่อยเรียกว่า **"โทเคน" (token)**
จำนวนโทเคนคือสิ่งที่กำหนดว่าบทสนทนากินพื้นที่ความจำ ("context") ไปเท่าไหร่ และถ้าใช้ API ก็คือสิ่งที่คิดเงิน

**TokenCal** คือสคริปต์เสริมที่ทำงานอยู่บนหน้าเว็บ claude.ai มันจะ:

- **นับโทเคนของทุกข้อความในแชท** แยกเป็น 2 ก้อน: ฝั่งที่เราพิมพ์ (Input) กับฝั่งที่ Claude ตอบ (Output)
- **นับให้ใหม่เสมอ** ทุกครั้งที่ Claude ตอบจบ — ไม่มีทางที่นับตกหล่นหรือตัวเลขค้างเก่า
- **จำยอดล่าสุดไว้ในโปรแกรม** เปิดแชทเดิมกลับมาก็เห็นทันที
- **สร้าง Checkpoint ได้** คือการ "ปักหมุด" ยอดโทเคน ณ จุดหนึ่งพร้อมตั้งชื่อและวันเวลา
- **มีปุ่มนับใหม่ทั้งหมด** พร้อมหน้าเทียบให้ดูว่า "ยอดเก่า vs ยอดใหม่" ต่างกันแค่ไหน ก่อนตัดสินใจว่าจะใช้ยอดไหน
- **เซฟไฟล์อัตโนมัติลงเครื่อง** จัดเป็นโฟลเดอร์ตามปี/เดือน/สัปดาห์/วัน โดยใช้ชื่อแชทเป็นชื่อไฟล์ — ถ้าภายหลังเปลี่ยนชื่อแชท มันจะตามไปแก้ชื่อไฟล์ให้เองด้วย

**ภาพรวมการทำงานทั้งระบบ:**

> **เบราว์เซอร์ (หน้า claude.ai)** → สคริปต์ TokenCal นับโทเคนและโชว์บนแผง
> → ส่งตัวเลขให้ **helper** (โปรแกรมจิ๋วในเครื่องคุณ ผ่านช่องทาง "localhost" ในเครื่องเท่านั้น — ไม่ผ่านอินเทอร์เน็ต)
> → helper เขียนไฟล์รายงานลง **โฟลเดอร์ของคุณ** เช่น `Y2026/M10/W42/D12/2026-10-12_16-30 ชื่อแชท.json`

ทั้งหมดนี้เกิดขึ้น "เงียบๆ" โดยคุณไม่ต้องกดเซฟอะไรเลย

## 2. สิ่งที่ต้องมีก่อนเริ่ม

| สิ่งที่ต้องมี | ทำไมต้องมี | หมายเหตุ |
|---|---|---|
| เบราว์เซอร์ **Firefox** หรือ Chrome | ไว้เปิด claude.ai | คู่มือนี้เขียนแบบ Firefox เป็นหลัก (Chrome ก็ใช้ได้เหมือนกัน) |
| ส่วนขยาย **Violentmonkey** | เป็น "บ้าน" ให้สคริปต์ TokenCal ทำงาน | ฟรี ติดตั้งจากหน้าเว็บของเบราว์เซอร์ |
| โปรแกรม **Node.js** | ใช้รัน "ผู้ช่วย" (helper) ที่เซฟไฟล์อัตโนมัติ | ฟรี ติดตั้งครั้งเดียว (~30 MB) |
| โฟลเดอร์สำหรับเก็บไฟล์ | ปลายทางของไฟล์รายงาน | เช่น `C:\Users\Name\tokencal` (Windows) — หรือเว้นว่างแล้วให้ระบบเติมโฟลเดอร์เริ่มต้นให้อัตโนมัติ |

**ทำไมต้องมี "helper"?** — เบราว์เซอร์ไม่อนุญาตให้สคริปต์บนเว็บเขียนไฟล์ลงโฟลเดอร์ที่เรากำหนดเองแบบเงียบๆ (เป็นเรื่องความปลอดภัย ถ้าไม่ห้าม หน้าเว็บไหนก็เขียนไฟล์ลงเครื่องเราได้)
helper คือโปรแกรมจิ๋วที่รันอยู่แต่ในเครื่องคุณ (ที่อยู่ `localhost` — คือ "เครื่องตัวเอง" ไม่ใช่อินเทอร์เน็ต) คอยรับข้อมูลจาก TokenCal แล้วเขียนไฟล์ให้ เท่านั้นเอง มันไม่ได้ทำอะไรอย่างอื่นเลย

## 3. ติดตั้งครั้งแรก (ทำครั้งเดียว)

### ขั้นที่ 1 — ติดตั้ง Violentmonkey

1. เปิด Firefox
2. ไปที่หน้า Add-ons ของ Mozilla แล้วค้นหา **Violentmonkey** (หรือเข้าเว็บ violentmonkey.github.io แล้วกดปุ่มติดตั้ง)
3. กด **Add to Firefox** → **Add** → รอสักครู่ จะมีไอคอนรูปมนุษย์สีส้มโผล่ขึ้นมาแถบเครื่องมือ

### ขั้นที่ 2 — ติดตั้งสคริปต์ TokenCal

1. คลิกไอคอน **Violentmonkey** → เลือก **Dashboard** (หรือกด `Alt+Shift+M` แล้วเลือก Dashboard)
2. กดปุ่ม **+** มุมซ้ายบน → เลือก **New** (สคริปต์ใหม่)
3. ลบข้อความตัวอย่างในช่องออกให้หมด
4. เปิดไฟล์ **`Claude.js`** ที่อยู่ในโฟลเดอร์นี้ด้วย Notepad (หรือโปรแกรมแก้ไขข้อความอะไรก็ได้) → กด `Ctrl+A` เพื่อเลือกทั้งหมด → `Ctrl+C` คัดลอก
5. กลับไปที่หน้า Violentmonkey → คลิกในช่องเขียนสคริปต์ → `Ctrl+A` แล้ว `Ctrl+V` วางทับให้หมด
6. กด **Ctrl+S** เพื่อบันทึก → ตั้งชื่ออะไรก็ได้ เช่น `TokenCal`
7. ปิดแท็บนั้นได้เลย

> **ถ้ามี TokenCal เวอร์ชันเก่าอยู่แล้ว** (เช่น `Claude.js` เดิมชื่ออื่น) ให้ใช้วิธีเดียวกันคือเปิดสคริปต์นั้นแล้ววางทับ — ตัวเลขที่เคยนับไว้จะไม่หาย

### ขั้นที่ 3 — ติดตั้ง "helper" ให้เซฟไฟล์อัตโนมัติ

#### ถ้าใช้ Windows

1. ติดตั้ง Node.js ก่อน (ถ้ายังไม่มี): เปิดเว็บ **nodejs.org** → ดาวน์โหลดรุ่น **LTS** → ดับเบิลคลิกไฟล์ที่โหลดมา → กด Next ไปเรื่อยๆ จนจบ
2. เปิดโฟลเดอร์นี้ (`TokenCal`) แล้ว **ดับเบิลคลิกไฟล์ `setup-autostart-windows.vbs`**
3. จะมีหน้าต่างข้อความขึ้นว่า "ติดตั้งเรียบร้อย ✅" → กด OK
   - ตั้งแต่นี้ ทุกครั้งที่เปิดเครื่อง helper จะเริ่มทำงานเองแบบเงียบๆ (มองไม่เห็นหน้าต่าง)
   - ตอนนี้มันเริ่มทำงานแล้ว
4. (แนะนำ) ทดสอบว่าใช้ได้จริง: **ดับเบิลคลิกไฟล์ `check-helper-windows.bat`**
   - จะมีหน้าต่างดำขึ้นมาแสดงผล — ถ้าเห็นเครื่องหมาย ✅ หลายบรรทัด แปลว่าทุกอย่างพร้อม (กดปุ่มใดก็ได้เพื่อปิดหน้าต่าง)
   - ถ้าขึ้น ❌ ให้ทำตามข้อความแนะนำบนหน้าต่างนั้น

> **เกี่ยวกับ autostart บน Windows (เผื่อไปหาใน Task Manager):**
> - หลังติดตั้ง จะเห็นรายการชื่อ **"TokenCal Helper"** ใน **Task Manager → Startup apps** สถานะ Enabled
>   (ถ้าเปิด Task Manager ค้างไว้ *ก่อน* ติดตั้ง จะไม่เห็น — มันสแกนตอนเปิด ให้ปิดแล้วเปิดใหม่)
> - กด **Disable** จากตรงนั้นได้เลย = ปิด autostart โดยไม่ต้องลบอะไร
> - เบื้องหลัง Windows ใช้ "ตัวเปิดแบบซ่อนหน้าต่าง" (wscript) ปลุก helper เพื่อไม่ให้มีหน้าต่างดำโผล่มา —
>   แต่ที่**รันอยู่จริงคือ helper ตัวเดียว** (node.exe) ถ้าเผลอเปิดซ้ำ ตัวที่สองจะปิดตัวเองอัตโนมัติทันที ไม่มีตัวซ้อน

#### ถ้าใช้ macOS

1. ติดตั้ง Node.js ก่อน (ถ้ายังไม่มี): เปิดเว็บ **nodejs.org** → ดาวน์โหลดรุ่น **LTS** → ดับเบิลคลิกติดตั้งตามขั้นตอน (ถ้าถนัด Homebrew อยู่แล้ว จะติดตั้งผ่านมันก็ได้ — ไม่บังคับ)
2. เปิดโฟลเดอร์นี้ใน **Finder** แล้ว **ดับเบิลคลิกไฟล์ `setup-autostart-macos.command`**
   - ครั้งแรก macOS อาจไม่ยอมเปิดให้ (เพราะไฟล์ถูกคัดลอกมาจาก Windows) → ให้ **คลิกขวาที่ไฟล์ → Open With → Terminal** แล้วกด Open ยืนยัน
3. จะเห็นข้อความ **"ติดตั้งและเปิดใช้แล้ว ✅"** เป็นอันเสร็จ
   - ตั้งแต่นี้ helper จะเริ่มเองทุกครั้งที่ล็อกอิน
4. ทดสอบ: **ดับเบิลคลิกไฟล์ `check-helper-macos.command`** (วิธีเปิดแบบเดียวกับข้อ 2)
   - ถ้าเห็นเครื่องหมาย ✅ หลายบรรทัด แปลว่าพร้อมใช้งาน

> **เกี่ยวกับ autostart บน macOS:** ระบบจะปลุก helper ตรงๆ ผ่านกลไกของ macOS ชื่อ launchd (รายการชื่อ `com.tokencal.helper`)
> ทำงานจริงก็**รันตัวเดียว**เหมือนฝั่ง Windows — เช็คสถานะได้จากการรันไฟล์ตรวจสอบข้างบน

> **หมายเหตุ macOS:** ขั้นตอน "คลิกขวา → Open With → Terminal" จำเป็นเฉพาะ**ครั้งแรก**เท่านั้น หลังจากนั้นดับเบิลคลิกได้ตามปกติ

## 4. เปิดใช้งานครั้งแรก + จับคู่โฟลเดอร์

1. เปิด **claude.ai** และเข้าแชทใดก็ได้ (URL ต้องมี `/chat/...`)
2. จะเห็น **แผง TokenCal** สีเข้มมุมขวาบนของหน้าจอ
3. กดปุ่ม **ตั้งค่าโฟลเดอร์** (บรรทัดล่างสุดของแผง)
4. ในหน้าต่างที่เปิดขึ้นมา:
   1. **รอ 1–2 วินาที** — ระบบจะพยายามเชื่อมต่อ helper เองอัตโนมัติ: หา Port เอง รับ Token เอง และเติมโฟลเดอร์เริ่มต้นของเครื่องให้เอง (จะเห็นข้อความสีฟ้า "จับคู่อัตโนมัติแล้ว")
      - ถ้าไม่ขึ้นข้อความ ให้กดปุ่ม **🔗 จับคู่อัตโนมัติ** เอง (ถ้ายังไม่ขึ้น = helper ยังไม่ทำงาน → ดูหัวข้อ 11)
   2. ช่อง **โฟลเดอร์เก็บไฟล์** — **ปล่อยว่างได้เลย!** ระบบเติมให้อัตโนมัติอยู่แล้ว (Windows: `C:\Users\Name\tokencal`, macOS: `/Users/Name/tokencal` โดย `Name` คือชื่อผู้ใช้ของคุณในเครื่องนั้น)
      - โฟลเดอร์นี้อยู่ในพื้นที่ส่วนตัวของคุณ **ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ** และปลอดภัยต่อการเขียนไฟล์
      - ถ้าอยากเก็บที่อื่น พิมพ์ path ที่ต้องการทับได้เลย
   3. กด **🧪 ทดสอบ** → ต้องขึ้น "เชื่อมต่อได้ และโฟลเดอร์พร้อมใช้งาน"
   4. กด **บันทึก & เปิดใช้** เป็นอันเสร็จ (หรือกด Enter ในช่องโฟลเดอร์ก็ได้ — ทุกอย่างที่จำเป็นถูกจับคู่ไว้แล้ว)
5. กลับมาที่แชท → เส้นสถานะล่างแผงจะกลายเป็น **📁 Sync: 🟢 …** = ระบบเริ่มเซฟอัตโนมัติแล้ว

**ครั้งแรกจะมีการโหลดไฟล์ข้อมูล (vocabulary) ขนาดประมาณ 4.7 MB จากอินเทอร์เน็ต** เพื่อให้ตัวนับโทเคนแม่นยำ — หลังจากนั้นโหลดอีกครั้งเดียวตอนติดตั้ง และจะถูกแคชไว้ ไม่ต้องโหลดซ้ำอีก

## 5. วิธีใช้ประจำวัน

### อ่านตัวเลขบนแผง

| ช่อง | ความหมาย |
|---|---|
| **Input** (สีฟ้า) | โทเคนรวมของทุกข้อความที่ **คุณ** พิมพ์ในแชทนี้ |
| **Output** (สีเขียว) | โทเคนรวมของทุกข้อความที่ **Claude** ตอบ |
| **Total** (สีม่วง) | ผลรวมสองอย่างข้างบน |
| **Messages** | จำนวนข้อความที่นับ (user + Claude) |

แถวเล็กๆ ใต้ตัวเลขจะบอก: รุ่นโมเดล, เวอร์ชันตัวนับ (Tokenizer), แหล่งที่มา และเวลาที่อัปเดตล่าสุด

### ระบบอัตโนมัติ (ค่าเริ่มต้น)

- ทุกครั้งที่ **Claude ตอบจบ** ระบบจะนับใหม่ทั้งแชทเอง แล้วบันทึกทับตัวเลขเดิม — ตัวเลขจึงตรงเสมอ ไม่ต้องกดอะไร
- เปิดแชทเก่า → เห็นยอดเดิมทันที แล้วระบบนับใหม่ให้สดๆ อีกครั้ง
- ถ้าไม่อยากให้ยิงอัตโนมัติ (เช่น เน็ตช้า) เอาติ๊กถูกที่ช่อง **Auto** ออกได้ เมื่อนั้นตัวเลขจะนิ่งจนกว่าจะกด **Recount** เอง

### ปุ่มต่างๆ ในแผง

| ปุ่ม | ทำอะไร |
|---|---|
| **↻ Recount** | นับใหม่ทั้งแชททันที แล้วเปิดหน้าเทียบเก่า/ใหม่ (ดูหัวข้อ 8) |
| **💾 Checkpoint** | ปักหมุดยอดโทเคนปัจจุบัน พร้อมตั้งชื่อและบันทึกวันเวลา |
| **📋 Checkpoints** | ดูรายการหมุดทั้งหมด — คัดลอกหรือลบได้ |
| **📄 Copy** | คัดลอกรายงานสรุป (รวมรายการหมุด) ไปวางในโน้ต/แชทได้เลย |
| **ตั้งค่าโฟลเดอร์** | ตั้งค่า/ตรวจสอบเรื่องเซฟไฟล์อัตโนมัติ |
| **▼ / ✕** (มุมขวาบนแผง) | ย่อแผง / ซ่อนแผง |

### สวิตช์ตั้งค่าในแผง (ควรรู้)

| ตัวควบคุม | ความหมาย |
|---|---|
| **Tok:** (Auto / v3 / v4.7 / v4.8) | รุ่นของตัวนับโทเคน — ปกติ **ปล่อย Auto** ระบบเลือกรุ่นให้เองตามโมเดลของแชท (เปลี่ยนเองเฉพาะตอนรู้แน่ว่ากำลังทำอะไร) |
| **thinking/tool** | ติ๊กถูก = นับส่วน "ความคิด" ของ Claude และการเรียกใช้เครื่องมือด้วย (ตัวเลขจะสูงขึ้น) |
| **Auto** | เปิด/ปิดการนับอัตโนมัติเมื่อ Claude ตอบจบ |
| **โหมด: ลอย / ฝัง** | รูปแบบการแสดงผล — ดูหัวข้อถัดไป |

### โหมดแสดงผล: ลอย vs ฝัง

TokenCal แสดงผลได้ 2 แบบ สลับได้ทันทีจากช่อง **โหมด** ในแผง (จำค่าไว้ให้ ไม่ต้องตั้งใหม่):

| | โหมด **ลอย** (ค่าเริ่มต้น) | โหมด **ฝัง** |
|---|---|---|
| ร่างย่อ | แผงเล็กมุมจอ — โชว์ `In · Out · Σ · turns` ขนาดย่อ | **แถบจิ๋วเหนือนช่องพิมพ์**: `In … · Out … · Σ … · … turns ●` |
| ร่างขยาย | แผงเต็ม (กด ▲) — **แสดงชื่อแชทแบบเต็ม ไม่ตัดคำ** | กดที่แถบจิ๋ว → **แผงเต็มฝังอยู่ในช่องพิมพ์เลย** (ขยายในที่ ไม่ลอย) |
| กลับร่างย่อ | กด ▼ | กด ▼ ที่แผง → กลับเป็นแถบจิ๋ว |

- **สีที่เห็นชัดในร่างย่อ**: `In` และตัวเลขเป็น**สีฟ้านีออน**, `Out` มี**จุดสีเขียวเต้นเป็นจังหวะ** + ตัวเลขสีเขียว, `Σ` สีม่วง, `turns` สีขาวสว่าง
  - ถ้าตั้งระบบ "ลดการเคลื่อนไหว" (Reduce Motion) ไว้ จุดจะหยุดเต้นอัตโนมัติ
- **จำนวน turns** (ข้อความทั้งหมดที่นับได้ในแชท) แสดงอยู่ในร่างย่อทั้งสองแบบ
- **ชื่อแชทเต็ม** จะแสดงเฉพาะตอนขยาย — ตอนย่อจะซ่อนไว้เพื่อความกระชับ (แผงย่อลอยจะเว้นระยะ "1 tab" ระหว่างคำว่า TokenCal กับ In)
- จุด ● ตัวแรกบนแถบจิ๋ว = สถานะเซฟไฟล์: 🟢 อัปเดตล่าสุดแล้ว / 🔴 helper ปิดหรือมีคิวรอ / ⚪ ปิดระบบเซฟไฟล์
- ซ่อนทุกอย่างได้ด้วย **✕** หรือคีย์ลัด **Ctrl+Shift+F** (Mac: Cmd+Shift+F) — กดซ้ำเพื่อเรียกกลับ
- ตัวเลขบนแถบจิ๋วคือชุดเดียวกับในแผง (In / Out / Total / จำนวนข้อความ ของแชทปัจจุบัน) อัปเดตพร้อมกันอัตโนมัติ
- ถ้าหาช่องพิมพ์ไม่เจอชั่วคราว (หน้าเว็บกำลังโหลด/เปลี่ยนหน้า) ระบบจะแสดงแผงย่อแบบลอยให้ก่อนชั่วคราว แล้วกลับมาเป็นแถบให้เองอัตโนมัติ — ไม่มีทางค้าง

### การแจ้งเตือน (ข้อความสั้นๆ) ขึ้นตรงไหน

การแจ้งเตือนต่างๆ เช่น "บันทึก Checkpoint แล้ว", "แชทถูกเปลี่ยนชื่อ" จะเด้งตามโหมดที่ใช้:

- **โหมดลอย** → เด้ง**เหนือนช่องพิมพ์** กลางคอลัมน์แชท
- **โหมดฝัง** → เด้ง**ใต้แถบชื่อแชทด้านบน** กลางคอลัมน์แชท

แสดงพร้อมกันสูงสุด 3 ข้อความ (อันใหม่สุดอยู่ใกล้ตำแหน่งอ้างอิงที่สุด) แล้วจางหายเองใน ~4 วินาที

### แถวข้อมูลใต้ตัวเลขอ่านยังไง

| ข้อความ | ความหมาย |
|---|---|
| Model: … | รุ่นโมเดลที่ตรวจพบจากแชทนี้ |
| Tokenizer: v… | รุ่นตัวนับที่ระบบใช้คำนวณ |
| ที่มา: **API** | นับจากข้อมูลแชททั้งหมด — โหมดปกติ แม่นและครบ 100% |
| ที่มา: **DOM (อาจไม่ครบ)** | โหมดสำรองตอนดึงข้อมูลตรงไม่ได้ชั่วคราว — ควรกด Recount ใหม่เมื่อทุกอย่างปกติ |
| ที่มา: **ข้อมูลเวอร์ชันเก่า** | ยอดเดิมที่ตกทอดมาจาก TokenCal เวอร์ชันก่อนหน้า (จะกลายเป็น API หลังนับรอบถัดไป) |
| อัปเดต: … | วันเวลาที่ตัวเลขถูกบันทึกล่าสุด |

### ทริคเล็กๆ

- **ลากแผง** ได้โดยจับที่แถบหัวแผง — ตำแหน่งจะถูกจำไว้ให้เอง
- **ย่อแผง** ให้เหลือแถบเล็กๆ ได้ด้วยปุ่ม ▼
- ถ้าซ่อนแผงไปแล้ว จะเรียกกลับมาด้วยคีย์ลัด **Ctrl+Shift+F** (เครื่อง Mac: Cmd+Shift+F)
- ตอนที่ Claude กำลังพิมพ์คำตอบยาวๆ ยอดจะอัปเดตเมื่อตอบจบแล้วเท่านั้น (เพื่อให้ตัวเลขตรงกับข้อความจริงที่ได้)

## 6. ไฟล์ถูกเก็บไว้ที่ไหน

เมื่อเปิดระบบเซฟอัตโนมัติ ทุกอย่างจะถูกจัดเรียงแบบ ISO (มาตรฐานสากล) ลึก 4 ชั้น:

- **โฟลเดอร์ที่คุณเลือก** (ชั้นนอกสุด)
  - **Y2026** — ปีตามมาตรฐาน ISO
    - **M10** — เดือน 10
      - **W42** — สัปดาห์ที่ 42 ของปี
        - **D12** — วันที่ 12
          - `2026-10-12_16-30 ชื่อแชทของฉัน.json`
          - `2026-10-12_18-05 แชทอื่น.json`

**กติกาง่ายๆ:**

- **1 แชท = 1 ไฟล์ต่อวัน** — วันเดียวกันนับกี่รอบก็เขียนทับไฟล์เดิม (เวลาในชื่อไฟล์คือเวลาที่เซฟครั้งแรกของวันนั้น)
- **ชื่อไฟล์ = วันเวลา + ชื่อแชท** เช่น `2026-10-12_16-30 เรื่องภาษี.json`
- **เปลี่ยนชื่อแชท → ชื่อไฟล์เปลี่ยนตามให้เอง** โดยวันเวลาเดิมยังอยู่
- ถ้ามี 2 แชทชื่อเหมือนกัน ระบบจะเติมรหัสสั้นๆ ต่อท้ายกันชนกัน เช่น `... ชื่อซ้ำ_3f9ab210.json`
- ชื่อแชทที่มีตัวอักษรต้องห้ามในชื่อไฟล์ (เช่น `/ \ : ? *`) จะถูกปรับให้ปลอดภัยอัตโนมัติ

**ข้างในไฟล์** มีข้อมูลทั้งหมดที่ระบบรู้: ชื่อแชท, รุ่นโมเดล, ยอด Input/Output/Total, จำนวนข้อความ, เวลาเซฟ, ที่มา และ **รายการ Checkpoint ทั้งหมด**

> 🔒 **ไฟล์นี้มีแค่ "ตัวเลข" เท่านั้น** — ไม่มีเนื้อหาบทสนทนาอยู่ข้างในเลย จึงส่งต่อหรือสำรองเก็บได้โดยไม่ต้องกังวลว่าจะเผยข้อความที่คุยกัน

**ไฟล์ระบบ** (ไม่ต้องไปแก้):
- `_tokencal_index.json` — สมุดจดของ helper ว่าแชทไหนอยู่ไฟล์ไหน (ลบได้ ระบบสร้างใหม่ได้ แต่ไม่จำเป็นต้องแตะ)
- `tokencal-helper.log` — บันทึกการทำงานของ helper เอาไว้ดูเวลามีปัญหา

> ไฟล์ถูกเก็บ**ในเครื่องคุณเท่านั้น** ไม่มีการอัปโหลดไปไหน

## 7. Checkpoint คืออะไร

ลองนึกว่าคุณคุยกับ Claude มา 2 ชั่วโมง แล้วอยากรู้ว่า "ณ จุดนี้ กินโทเคนไปเท่าไหร่แล้ว"
Checkpoint คือการ**ปักหมุดตัวเลข ณ วินาทีนั้น** พร้อมตั้งชื่อ เช่น

- `หลัง写完บทที่ 1`
- `ก่อนเริ่มแก้โค้ดใหญ่`
- `ส่งงานให้ลูกค้าแล้ว`

**วิธีใช้:** กด **💾 Checkpoint** → พิมพ์ชื่อ → Enter → เสร็จ (ระบบบันทึกวันเวลาให้เอง)

ตอนนี้หมุดจะถูกเก็บไว้ 2 ที่:
1. ในโปรแกรม (ดูได้จากปุ่ม **📋 Checkpoints** — ลบ/คัดลอกได้รายหมุด)
2. ในไฟล์ JSON ประจำวันด้วย — เปิดไฟล์เมื่อไหร่ก็เห็นประวัติหมุดครบ

**ข้อดีที่สำคัญ:** ตัวเลข "ยอดปัจจุบัน" ต่อให้ข้อมูลในโปรแกรมหาย ก็คำนวณกลับมาใหม่ได้เสมอ — แต่ **หมุดที่คุณตั้งชื่อไว้ คือสิ่งเดียวที่คำนวณย้อนหลังไม่ได้** มันคือบันทึกประวัติของคุณ

## 8. Recount — นับใหม่และเทียบเก่า/ใหม่

ใช้เมื่อไหร่? เช่น คุณเปลี่ยนใจเปิด-ปิดโหมดนับ thinking, สงสัยว่ายอดเพี้ยน, หรือแค่อยากรู้ความต่างจากครั้งก่อน

เมื่อกด **↻ Recount** ระบบจะ:

1. นับใหม่ทั้งแชทจากข้อมูลจริงล่าสุด
2. เปิด**หน้าต่างเทียบ** ให้เห็นทีละบรรทัด:

| | ค่าเก่า (ที่บันทึก) | ค่าใหม่ (Recount) | ต่าง |
|---|---|---|---|
| Input | 12,345 | 12,400 | +55 |
| Output | 8,111 | 8,150 | +39 |
| … | … | … | … |

3. ให้คุณเลือก:
   - **📄 Copy ค่าเก่า / 📄 Copy ค่าใหม่** — คัดลอกรายงานฝั่งนั้นเก็บไว้ก่อนได้
   - **เก็บค่าเดิม** — ปิดหน้าต่าง ไม่มีอะไรเปลี่ยน
   - **ใช้ค่าใหม่ (บันทึก)** — เอาค่าใหม่ทับ

จุดสำคัญ: **ระบบจะยังไม่ลบหรือทับค่าที่บันทึกไว้ จนกว่าคุณจะกด "ใช้ค่าใหม่"** — คุณตัดสินใจเองเสมอ

## 9. ความแม่นยำของตัวเลข

ตัวนับของ TokenCal สร้างจากโปรเจกต์วิจัยโอเพนซอร์สชื่อ **ctok** ซึ่งถอดแบบวิธีนับโทเคนของ Claude จากผลวัดจริงหลายแสนเคส (ครอบคลุม 350 ภาษารวมภาษาไทย โค้ด และอีโมจิ) ผลทดสอบกับข้อความกว่า **16,000 เคส** ตรงกับตัวนับอ้างอิง 100% — แม่นพอสำหรับใช้งานจริงทุกแบบ

สิ่งที่ควรรู้:

- **ตัวเลขคือโทเคนของ "เนื้อหาข้อความ"** — ไม่ใช่ยอดที่ระบบคิดเงินจริง (การคิดเงินนับบริบทย้อนหลังทั้งหมดต่อเทิร์น ซึ่งมากกว่านี้) ใช้ดูว่าแชทเริ่มหนักแค่ไหนได้ดีมาก
- **มีสวิตช์ "thinking/tool"** — ค่าเริ่มต้นนับเฉพาะข้อความหลัก ถ้าเปิดจะนับส่วน "ความคิด" ของ Claude และการเรียกใช้เครื่องมือด้วย (ตัวเลขจะสูงขึ้น)
- **ระบบเลือกตัวนับตามรุ่นโมเดลให้เองอัตโนมัติ** (เพราะรุ่นใหม่กว่ามีวิธีตัดคำที่ต่างจากรุ่นเก่า) — ปกติไม่ต้องแตะ (สวิตช์ **Tok:** มีไว้สำหรับกรณีพิเศษเท่านั้น)
- **แชทที่มีการแก้ข้อความหรือสั่งตอบใหม่ (branch):** ระบบนับตามเส้นทางที่คุณเห็นอยู่บนหน้าจอ ณ ตอนนั้น — กิ่งเก่าที่ถูกแทนไปแล้วไม่ถูกนำมานับ
- **ไฟล์แนบและรูปภาพไม่ถูกนับ** — นับเฉพาะข้อความตัวอักษร (ไฟล์แนบมีวิธีคิดโทเคนของมันเองที่ต่างออกไป)
- **Opus 5.x:** รุ่นนี้มีการเปลี่ยนแปลงเล็กน้อยที่งานวิจัยยังไม่ได้ถอดแบบครบ ระบบจะแสดงหมายเหตุเตือน — ถ้าใช้รุ่นนี้อยู่ให้เผื่อคลาดเคลื่อนเล็กน้อย
- ถ้าอินเทอร์เน็ตหลุด/ระบบภายในแชทเปลี่ยน และตัวสคริปต์ดึงข้อมูลทางตรงไม่ได้ มันจะสลับไปนับจาก "ข้อความที่มองเห็นบนหน้าจอ" แทนและขึ้นเครื่องหมาย ⚠ เตือน — ตัวเลขอาจไม่ครบ 100% ให้กด Recount ใหม่เมื่อเน็ตกลับมา

|---|---|---|
| ยอดโทเคน, Checkpoint, การตั้งค่า | ในตัวจัดการสคริปต์ (Violentmonkey) | ลบสคริปต์ทิ้งแล้วลงใหม่ / ล้างข้อมูลส่วนขยาย / เปลี่ยนเครื่องใหม่ |
| ไฟล์รายงาน JSON | โฟลเดอร์ที่คุณเลือก (ในเครื่อง) | คุณลบเองเท่านั้น |
| Token/พอร์ตของ helper | ไฟล์ `tokencal-helper.config.json` ในโฟลเดอร์นี้ + การตั้งค่าในสคริปต์ | ลบไฟล์/ตั้งค่าใหม่ |

**ออกอินเทอร์เน็ตไหม?**
- ไม่มีข้อมูลออกไปไหนทั้งสิ้น ยกเว้น:
  1. การขอไฟล์ข้อมูลนับโทเคน (ครั้งเดียวตอนติดตั้งแรก) จากเว็บโอเพนซอร์ส GitHub
  2. การนับโทเคนจะดึงข้อความแชทจาก claude.ai เอง (ก็คือ "หน้าเว็บที่คุณเปิดอยู่แล้ว" นั่นแหละ — ไม่ได้ส่งไปที่ใหม่)
- helper รับส่งข้อมูลผ่าน `127.0.0.1` เท่านั้น (ในเครื่องตัวเอง) คนละเรื่องกับอินเทอร์เน็ตเลย

## 11. แก้ปัญหาเบื้องต้น

### แผง TokenCal ไม่ขึ้น

- เช็คว่า URL เป็นแชทจริง (มี `/chat/`) เช่น `https://claude.ai/chat/xxxx` — หน้าแรก หน้า Settings หรือหน้าโปรเจกต์ สคริปต์จะยังไม่ทำงาน (แชทที่อยู่ในโปรเจกต์: เปิดแชทนั้นจากในโปรเจกต์ URL จะเปลี่ยนเป็น `/chat/` เอง แล้วแผงจะขึ้นตามปกติ)
- รีเฟรชหน้า (F5) หนึ่งครั้ง
- เช็คใน Violentmonkey ว่าสคริปต์ TokenCal **เปิดใช้งาน** อยู่ (ติ๊กถูกสีเขียวที่ชื่อสคริปต์)

### ตัวเลขไม่ขยับ / ค้าง

- ถ้า **Auto** ถูกปิดไว้ ต้องกด **Recount** เอง
- ถ้าเพิ่งเปิดแชท ให้เวลาสัก 2–3 วินาที
- ดูบรรทัดสถานะใต้ตัวเลขว่ามีข้อความแจ้งปัญหาอะไรไหม

### สถานะ Sync ขึ้น 🔴 ออฟไลน์

แปลว่าเบราว์เซอร์คุยกับ helper ไม่ได้:

1. เช็คว่า helper ทำงานอยู่: **ดับเบิลคลิก `check-helper-windows.bat`** (Windows) หรือ **`check-helper-macos.command`** (macOS) — มีวิธีเปิดในหัวข้อ 3
2. ถ้าขึ้น ❌:
   - ตรวจว่าติดตั้ง Node.js แล้วจริง
   - Windows: ลองดับเบิลคลิก `start-helper-windows.bat` (จะมีหน้าต่างดำขึ้น = กำลังทำงาน) แล้วตรวจอีกครั้ง → ถ้าได้ ให้ดับเบิลคลิก `setup-autostart-windows.vbs` ใหม่
   - macOS: คลิกขวาที่ไฟล์ `start-helper-macos.command` → Open With → Terminal แล้วตรวจอีกครั้ง
3. ดูสาเหตุละเอียดได้ในไฟล์ `tokencal-helper.log`
4. ตัวเลขไม่หายตอน helper ปิด — ทุกอย่างจะถูกเก็บรอไว้ในคิว แล้ว**เซฟให้เองอัตโนมัติเมื่อ helper กลับมา** (สถานะจะโชว์ "คิว N")

### Task Manager (Windows) ไม่เห็น "TokenCal Helper"

- Task Manager สแกนรายการ startup ตอนเปิดหน้าต่าง — ถ้าเปิดค้างไว้ก่อนติดตั้ง ให้ปิดแล้วเปิดใหม่
- เช็คว่ามีไฟล์ shortcut จริง: เปิด **File Explorer** แล้วไปตามนี้ทีละขั้น: **This PC → (ไดรฟ์ C:) → Users → (ชื่อผู้ใช้ของคุณ) → AppData → Roaming → Microsoft → Windows → Start Menu → Programs → Startup** — ดูว่ามีไฟล์ `TokenCal Helper` อยู่ในนั้น
  - (ถ้ามองไม่เห็นโฟลเดอร์ AppData: ที่แถบด้านบนของ File Explorer กด View → Show → ติ๊กถูกที่ "Hidden items")
- ถ้าไม่มี ให้ดับเบิลคลิก `setup-autostart-windows.vbs` อีกครั้ง

### กด "จับคู่อัตโนมัติ" แล้วไม่เจอ helper

- ตรวจว่า helper เปิดอยู่ (ข้อข้างบน)
- ตรวจว่าเลข Port ในหน้าตั้งค่าตรงกับในไฟล์ `tokencal-helper.config.json` (ค่าปกติคือ 3210)

### ขึ้น "ที่มา: DOM (อาจไม่ครบ)"

- แปลว่า TokenCal ดึงข้อมูลตรงจากแชทไม่สำเร็จชั่วคราว จึงอ่านจากข้อความที่มองเห็นบนหน้าจอแทน
- สาเหตุพบบ่อย: ล็อกอินหลุด/คุกกี้หมดอายุ → รีเฟรชหน้าแล้วเช็คว่ายังล็อกอินอยู่
- เมื่อทุกอย่างปกติ ให้กด **Recount** อีกครั้ง ตัวเลขจะกลับมาครบและขึ้น "ที่มา: API"

### เซฟไฟล์แล้วไม่เห็นไฟล์

- เช็คโฟลเดอร์ที่ตั้งไว้ (กด ตั้งค่าโฟลเดอร์ → 🧪 ทดสอบ ต้องขึ้นสีเขียว)
- โฟลเดอร์ต้องมีสิทธิ์เขียน — เลือกโฟลเดอร์ในพื้นที่ผู้ใช้ตัวเอง เช่น `C:\Users\Name\...` (Windows) หรือ `/Users/Name/...` (macOS) ซึ่ง**ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ**

### เปิดครั้งแรกแล้วค้างที่ "กำลังโหลด vocab"

- ครั้งแรกต้องต่ออินเทอร์เน็ตเพื่อโหลดไฟล์ข้อมูล ~4.7 MB (รอสักครู่)
- ถ้าโหลดไม่ได้เลย (เน็ตบริษัทบล็อก GitHub) ให้ลองเน็ตอื่น แล้วเปิดแชทอีกครั้ง — โหลดสำเร็จครั้งเดียวก็พอ

## 12. คำถามที่พบบ่อย

**Q: ต้องเปิดคอมทิ้งไว้ไหม?**
ไม่ต้อง ไฟล์จะถูกเซฟเมื่อคุณใช้งาน claude.ai — วันที่ไม่เปิดก็แค่ไม่มีไฟล์ของวันนั้น

**Q: ไฟล์จะซ้ำกันไหมถ้านับหลายรอบ?**
ไม่ วันเดียวกันเขียนทับไฟล์เดิม ตัวเลขในไฟล์คือยอดล่าสุดเสมอ

**Q: เปลี่ยนชื่อแชทบน claude.ai แล้วไฟล์เก่าจะเป็นยังไง?**
ระบบจะเปลี่ยนชื่อไฟล์ให้ทันทีเมื่อตรวจเจอ (จะขึ้นข้อความแจ้งเตือนด้วย) — วันเวลาเดิมคงอยู่

**Q: ย้ายโฟลเดอร์เก็บรายงาน (ปลายทางไฟล์) ทำยังไง?**
กด ตั้งค่าโฟลเดอร์ → ใส่ path ใหม่ → ทดสอบ → บันทึก (ไฟล์เก่าไม่ย้ายตาม ต้องคัดลอกเองถ้าต้องการ)

**Q: ต้องใช้สิทธิ์ผู้ดูแลระบบ (แอดมิน) ไหม?**
ไม่ต้องเลย — ค่าเริ่มต้นคือโฟลเดอร์ส่วนตัวของคุณ (`C:\Users\Name\tokencal` หรือ `/Users/Name/tokencal` โดย `Name` คือชื่อผู้ใช้ของคุณ) ซึ่งเขียนไฟล์ได้ทันทีโดยไม่ต้องแอดมิน
สิ่งที่ต้องแอดมินคือโฟลเดอร์ระบบ เช่น `C:\` ตรงๆ, `Program Files`, `Windows` — ไม่ต้องไปยุ่ง

**Q: ถ้าไม่กรอกโฟลเดอร์เลย จะเกิดอะไรขึ้น?**
กดบันทึก (หรือกด Enter) โดยช่องว่างไว้ — ระบบจะขอค่าเริ่มต้นจาก helper แล้วเติมให้อัตโนมัติเป็น `<โฟลเดอร์บ้านของคุณ>\tokencal` (ทุกเครื่องได้ path ที่เหมาะกับตัวเอง ไม่ต้องจำ)

**Q: helper กินสเปกเครื่องไหม?**
น้อยมาก มันแค่รอฟังคำสั่งเป็นครั้งคราว (หน่วยความจำหลักสิบ MB ตอนว่าง)

**Q: ย้ายโฟลเดอร์ TokenCal ไปที่อื่นได้ไหม?**
ได้ แต่ **autostart จะยังชี้โฟลเดอร์เก่า** — หลังย้ายให้เปิดตัวติดตั้ง autostart จากโฟลเดอร์ใหม่หนึ่งครั้ง (Windows: ดับเบิลคลิก `setup-autostart-windows.vbs` / macOS: เปิด `setup-autostart-macos.command`) ตัวติดตั้งจะเขียนทับรายการเดิมให้เองโดยไม่ซ้อนกัน

**Q: autostart ของ Windows กับ macOS ต่างกันยังไง? จะรันสองตัวไหม?**
คนละกลไก แต่ผลเหมือนกัน — **รัน helper ตัวเดียวทั้งคู่**:
- Windows: shortcut ใน Startup → "ตัวเปิดแบบซ่อนหน้าต่าง" → node (helper) — ใน Task Manager เห็นรายการเดียวชื่อ "TokenCal Helper"
- macOS: launchd ปลุก node ตรงๆ — รายการเดียวชื่อ `com.tokencal.helper`
ถ้าเผลอเปิดซ้ำ ตัวที่สองจะปิดตัวเองทันที (เห็นข้อความ "address already in use" ใน log) — ไม่มีทางรันซ้อนสองตัว

**Q: อยากหยุด helper ชั่วคราว โดยไม่ถอนการติดตั้ง ทำยังไง?**
วิธีที่สะอาดที่สุดคือเปิดตัวถอน (`remove-autostart-...`) — มันจะหยุด helper ที่รันอยู่ **และ** ยกเลิกการเปิดอัตโนมัติ; เมื่ออยากใช้ต่อก็เปิดตัวติดตั้ง (`setup-autostart-...`) อีกครั้ง **ไม่มีข้อมูลหาย** เพราะยอดจะถูกเก็บคิวไว้ในโปรแกรมและซิงก์ให้อัตโนมัติเมื่อ helper กลับมา

**Q: อยากสำรองข้อมูลในโปรแกรม (ยอด / Checkpoint / ตั้งค่า) ทำยังไง?**
เปิด **Violentmonkey Dashboard → Values** จะเห็นค่าทั้งหมดของ TokenCal และมีปุ่ม Export เป็นไฟล์ JSON ไว้กู้คืนได้ — หรือใช้ปุ่ม **📄 Copy / 📋 Checkpoints** ในแผงเก็บเป็นข้อความก็ได้

**Q: ปิดเครื่อง/รีสตาร์ทแล้วข้อมูลยังอยู่ไหม?**
อยู่ครับ ทั้งยอดในโปรแกรมและไฟล์ในโฟลเดอร์ ยกเว้นกรณีลบสคริปต์ทิ้งแล้วลงใหม่ / ล้างข้อมูลส่วนขยาย / ย้ายเครื่องใหม่ (รายละเอียดในหัวข้อ 10)

**Q: ใช้ Chrome/Edge ได้ไหม?**
ได้ สคริปต์ทำงานเหมือนกัน (แต่คู่มือนี้เน้น Firefox)

**Q: ถ้าอยากได้ข้อมูลกลับคืนหลังเปลี่ยนเครื่อง?**
คัดลอกโฟลเดอร์ `TokenCal` (รวมโฟลเดอร์เก็บไฟล์รายงาน) ไปเครื่องใหม่ แล้วทำตามหัวข้อ 3 อีกครั้ง — ส่วนประวัติในโปรแกรม (คิว/ตำแหน่งแผง) เริ่มใหม่ แต่ยอดโทเคนสร้างใหม่ได้เสมอจากการนับ และไฟล์รายงานยังอยู่ครบ

## 13. ถอนการติดตั้งทั้งหมด

1. **ปิด autostart ของ helper:**
   - Windows: ดับเบิลคลิก `remove-autostart-windows.vbs`
   - macOS: คลิกขวาที่ไฟล์ `remove-autostart-macos.command` → Open With → Terminal (หรือดับเบิลคลิกถ้าเปิดได้ตามปกติ)
2. **ลบสคริปต์ในเบราว์เซอร์:** Violentmonkey Dashboard → หา TokenCal → กดปุ่มลบ
3. (ทางเลือก) ลบไฟล์ในโฟลเดอร์เก็บรายงานตามใจชอบ
4. (ทางเลือก) ถอน Node.js ถ้าไม่ใช้ทำอย่างอื่น
